# The red flags

Each flag below is a shape of wording that reads as content and carries none. The main file
names all six; this is what each one looks like, what it costs, and what a flag usually means
underneath. Reach for this while auditing inherited wording - the audit itself, its two gates
and its worked cases are in `references/auditing-it.md`.

## A quality adjective with no test

helpful, thorough, rigorous, thoughtful, clean, robust, elegant, professional, delightful.

Ask how to check it. If the answer is a feeling, rewrite as the action it was standing in for.
The adjective is not decoration: it is an instruction nobody can follow and nobody can check,
and it survives because agreeing with it costs nothing.

## Cargo-culted structure

A shape everyone follows - a triad, a template, a section order - that forces content to fill
slots that do not exist in the material. The tell is a section that has to be padded to keep
the shape, or a third item that exists only because the other two do.

## Soft attribution

"It is well known", "studies show", "classically", "as X said". The hedging is where the
verification is missing: the writer did not check, so the sentence borrows someone else's
authority instead of stating its own evidence. The rule the flag breaks is in
`references/writing-it.md`, under **Make it verifiable** - hedge only where uncertainty is
real, and then say what would remove it.

## A rule that contradicts another rule nearby

One of the two was inherited and never reconciled. Find out which by asking which one has a
failure mode behind it: the rule that names the failure it prevents is the one that was
decided, and the other is the one that arrived.

## A metaphor standing in for a mechanism

A vivid image can hide the fact that the mechanism was never described. The metaphor is worth
keeping only after the mechanism is written down; before that, it is the reason nobody
noticed the mechanism was missing.

## An absolute with no counterexample

"Always", "never", "best" - a rule with no situation that violates it is decoration. If you
cannot name a case the rule is meant to stop, either the rule has a narrower form you have not
found yet, or there was nothing to rule out.
