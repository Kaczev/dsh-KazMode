# kaz-agent-preset-display —— 新对话预设显示补丁插件

> **作用**：修正 dsh 新对话 hero 上「agent 预设」按钮的显示——让按钮优先显示该空白对话自己选择的预设，而不是被全局默认/刷新误导。

## 为什么需要它（原 dsh 的显示问题）

如果新建对话时你选了**模式 A**，但设置里的默认预设是**模式 B**，接着刷新了浏览器，
官方按钮会显示成**模式 B**；如果你不主动再调模式，发了第一条消息后才会显示回
模式 A。本插件让按钮**优先显示空白会话自己的 agentPreset**，避免这种错显。

## 实现

- 宿主侧只注册一个 settings 命名空间（`enabled` 默认 `true`），让 Kaz 控制面板能
  读取/开关这个补丁插件；
- 客户端注册替换 `conversation.hero.agentPreset` 插槽（order/priority -9999），
  用自己的预设选择按钮替代官方按钮。

## 特性

- **常驻补丁**：Kaz 模式和非 Kaz 模式下都默认开启，**不随 Kaz 模式开关关闭**；
- **Kaz 面板可关**：Kaz 面板「补丁插件（常驻）」区块里有它的开关行；
- **暂存逻辑**：没有可接收的空白会话时先暂存选择，等会话出现后自动应用。

## 安装（与其它插件一致）

KazPlugins 目录随 profile 以 `file:` 依赖 + junction 装配；`cordis.patch.yml` 插入
`kaz-agent-preset-display` 行（config: `enabled: true`）。改完**重启 dsh + 强刷页面**。

## 验收要点

1. 新对话 hero 上预设按钮显示该对话自己选择的预设（不被默认/刷新带偏）；
2. 切预设后 Kaz 面板的「当前预设」随之同步（依赖 kaz-mode 的会话联动）。
